Project 1 - "NexusFlow": Visual IoT Telemetry & Rule Engine
Problem Statement: Hardcoding logic for IoT devices (e.g., "If temperature > 80°C, send an alert") requires
developer intervention for every business rule change. Standard MERN apps struggle to store and query
high-frequency machine data efficiently while simultaneously running dynamic, user-defined logic against
continuous data streams.
Use Case: A factory floor manager logs into NexusFlow. Using a React-based visual drag-and-drop canvas,
they connect a "Turbine Sensor" node to a "Moving Average Filter" node, and finally to an "SMS Alert"
node. The Node.js backend instantly compiles this visual graph into an executable data stream. As millions
of telemetry points pour into the optimized MongoDB Time-Series collections, the custom rule executes
in real-time, instantly notifying the manager when anomalies occur.
Key Modules:
• Visual Graph Builder (React & React Flow): A node-based UI allowing non-technical users to build
complex logic trees and data pipelines.
• Time-Series Database (MongoDB 5.0+): Utilizes native MongoDB Time-Series collections
optimized for high-ingest, append-only sensor data.
• Stream Compiler (Node.js & RxJS): Backend engine that translates the JSON graph from the
frontend into highly concurrent, reactive data streams (Observables).
• Ingestion API (Express & WebSockets): High-throughput endpoints to receive mock hardware
telemetry and broadcast alerts back to the client.
